# Dreem Sabiniano — Administrative & Operations VA Portfolio

Static site built with HTML, CSS, and vanilla JavaScript. No build step or framework.

## Preview locally
Open `index.html` in a browser. For the best experience, use a local static server because browser clipboard permissions and PDF iframe behavior vary for `file://` pages.

## Edit content
All editable copy, project links, tool names, availability text, and service descriptions are in `content.js`.

## Before publishing
Replace these placeholders in `content.js`:
- `[CALENDLY_LINK]`
- `[AVAILABILITY]`
- `[TIMEZONE_HOURS]`

The Notion previews may be blocked by the host's embed policy. Each project card therefore retains an on-brand static poster and opens the full project in a new tab. The three supplied PDF samples are included in the root folder.

## Publish with GitHub Pages
Upload the contents of this folder (not the enclosing folder) to the repository root on the `main` branch. Keep `index.html`, `styles.css`, `content.js`, `script.js`, image assets, and PDFs together in the root.
